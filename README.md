# Здобич — розширення для Owlbear Rodeo

Генератор скарбів за таблицями DMG. Видає здобич просто в листи персонажів:
монети додаються до гаманця, предмети — у вкладку «Спорядження».

## Три способи

**Скарбниця** — знайдений схрон. Монети, самоцвіти або витвори мистецтва,
з шансом на магічні речі. Шанс і рівень магії ростуть із рангом.

**З кишень** — те, що носив при собі один ворог. Тільки монети.

**З ворогів на сцені** — рахує здобич з усіх ворогів, створених розширенням
«Сутички», за їхнім CR. Зручно одразу після бою.

## Видача

Під результатом список персонажів із галочками. Монети діляться порівну,
залишок від ділення йде першому. Предмети роздаються по колу.

Однакові предмети в листі не плодяться рядками, а збільшують кількість.

## Чому не Loot Stash

Loot Stash — закритий сервіс: дані на їхньому сервері за автентифікацією,
публічного API немає, гравці бачать інвентар у власному застосунку.
Дотягнутися до нього ззовні неможливо. Зате таблиці скарбів DMG відкриті,
а листи персонажів у нас свої — тож генерація і видача зроблені на місці.

## Залежності від інших розширень

Ключі мають збігатися з тими, що в сусідніх розширеннях:

- `com.nikita.character-sheet/sheets` — листи персонажів
- `com.nikita.encounter/monster` — мітка на ворогах для режиму «з ворогів»

Без розширення «Лист персонажа» видавати нікуди. Без «Сутичок» не працює
лише третій режим.

## Обмеження

У листі персонажа є золоті, срібні й мідні — платини немає. Тому платина
переводиться в золото за курсом десять до одного.

Назви магічних речей узагальнені, без прив'язки до конкретних правил.
Правити їх у `src/tables.js`, розділ `MAGIC`.
